# Airline Data Analysis Using Spark Technologies

## About Project

This project analyzes airline flight data using **Python, PySpark, and Apache Spark**.

The main purpose is to analyze flight delays and cancellations and predict whether a flight will be cancelled.

## Technologies Used

- Python
- PySpark
- Apache Spark
- Pandas
- Spark MLlib
- Logistic Regression

## Project Modules

1. Data Profiling
2. Data Cleaning
3. Data Analysis
4. Feature Engineering
5. Machine Learning
6. Prediction and Evaluation

## Machine Learning

The project uses **Logistic Regression** to predict flight cancellation.

- `0` → Not Cancelled
- `1` → Cancelled

## Result

The current implementation achieved approximately **98.42% accuracy**.

## How to Run

Install PySpark:

```bash
pip install pyspark
```

Run the project:

```bash
python airline_analysis.py
```
